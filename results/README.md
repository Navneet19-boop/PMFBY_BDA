# Historical evidence, not a new run

`historical_run.json` records the accepted v2.2 run of 7 September 2026.
`historical_evaluation.json` records the saved-output supplement of 8 September.
The two CSVs contain a compact evidence-tier comparison and example worklist.

The worklist is a small example, not all two million scenarios or the complete
priority queue. Hidden simulator probability is not part of the worklist.

The historical JSON names original workspace tables for traceability. Those
names are not executable dependencies in this package. Newly generated evidence
belongs to the fresh Delta prefix and ignored `artifacts/` folder.
